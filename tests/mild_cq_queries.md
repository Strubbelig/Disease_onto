# MILD competency questions: the queries that decide the test

Generated by `tests/run_mild_cq_tests.py --dump-queries` on 2026-10-30 for MILD file `mild_2026-10-30g.ttl`; default reasoner ELK.

The runner merges `tests/mild_cq_test_2026-10-30.ttl` (named individuals) with the full MILD import closure, reasons it with ROBOT (ELK by default, HermiT with `--reasoner HermiT`), writes the inferred class assertions into the output and runs every query below as a SPARQL ASK over that output. An *expected entailment* must come back true, an *expected non-entailment* false. *Probe classes* (in `tests/mild_cq_probes_2026-10-30.ttl`) are reasoned in a second run and must be reported unsatisfiable. A question passes only if every one of its checks passes; a query that errors fails its question.

## What the reasoner cannot decide

ELK implements OWL 2 EL: it ignores inverse-property axioms, `owl:differentFrom` and inverse-functional properties, and it never derives `owl:sameAs`. Under ELK the "not identical" checks therefore show that nothing in the axioms *could* force an identity (no functional or inverse-functional property, no cardinality cap) and that the reasoned output holds no `owl:sameAs`. Under HermiT the asserted `owl:differentFrom` pairs make a forced identity an inconsistency, so the main run would fail.

OWL has no time index. CQ4 is checked as far as a reasoner can: one individual keeps two successive constituents, they are not identified, and no axiom closes or fixes the parts of a material disease entity.
